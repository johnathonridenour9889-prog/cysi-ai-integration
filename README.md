# CYSI — AI Integration Consulting Website

Production-style AI integration consulting website and assessment workflow created for **CYSI (Cyber Systems Integration)**.

## What This Project Demonstrates

- Next.js / React front-end development
- TypeScript and responsive UI development
- Interactive systems-integration visualization
- AI / automation consulting workflow design
- PHP server-side assessment intake
- API / webhook integration architecture
- Automated confirmation-email workflow
- Static export and traditional web-hosting deployment
- Security-conscious separation of source code and credentials

## Major Features

### Interactive Integration Map
Visualizes how CRM, SQL, documents, APIs, assistants, automation, reporting, and human decision controls connect around an AI integration layer.

### AI Assessment Intake
Collects contact details, current systems, areas of interest, and workflow problems to support a structured discovery process.

### Server-Side Processing
`public/api/assessment.php` handles the assessment workflow. Production credentials are not stored in this public repository.

### Human-in-the-Loop Design
The site emphasizes explicit approval paths, measurable outcomes, and controlled automation rather than uncontrolled AI deployment.
